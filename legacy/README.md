# Archived coursework

These files preserve the original implementation. They are outside the supported
workflow. In particular, `runproject.py` can reuse validation as test and
`plm_classifier.py` does not restore the best checkpoint. The old data locations
have not been recreated here.

Use the root `sentiment` CLI and `notebooks/colab_training.ipynb` instead.
`data_augmentation.py` copies labels without semantic verification and is not
evidence of an evaluated synthetic-data pipeline.
